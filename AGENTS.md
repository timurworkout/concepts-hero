# Работа над ON MOVE

- Отвечай по-русски. Задавай по одному вопросу за сообщение и жди ответа.
- Сначала читай `project/intent.md`: это текущий вектор проекта. `PRODUCT.md` — подтверждённый продуктовый контекст для Impeccable. Учитывай `project/tone-of-voice.md` и `project/plan.md`.
- При поиске нового визуального решения сначала предложи несколько различающихся HTML-превью (обычно три) и покажи их в браузере. Храни новые превью в `project/previews/`. После выбора автора переноси выбранный вариант в основной интерфейс. Это подтверждённый порядок работы, а не просьба сразу менять приложение.
- Настройка Impeccable `buildPath` хранится в `.impeccable/config.json`. HTML-превью создаются кодом; предварительная генерация изображения не требуется.
- Сохраняй открытые продуктовые вопросы нерешёнными. Фидбек менторов — рекомендации; решения принимает автор. Не меняй `project/intent.md` без прямой просьбы.
- Темп: концепт собираем, а не полируем. Чини только то, что видно глазом на скриншотах 1440 и 390; мелочи — в список «потом». Проверки прогоняй одним пакетом в конце, а не после каждой правки. Если Impeccable требует возни с деталями — сначала спроси автора, надо ли упарываться. Подробнее в `README.md`.
- Визард с автоматическими переходами — ключевой UX концепта. При изменении первого экрана сохраняй настоящую механику и проверяй открытые панели, а не только закрытую полосу. Размещай визард выше, оставляя достаточно высоты для календаря и остальных опций; мобильные полноэкранные шторки сохраняй.
