## Карточка машины

### Т-Банк Авто — приложение Т-Банка, скриншоты 05.10.2026
- **Фокус UI/UX:** покупка авто; одна длинная страница машины, кнопки закреплены внизу.
- **Структура страницы (сверху вниз):** [скрин]
  1. Фото на нейтральном студийном фоне, листается.
  2. Модель, цена крупно; старая цена зачёркнута, скидка зелёным.
  3. Выбор цвета — квадратные свотчи, подпись выбранного цвета.
  4. Кратко одной строкой: привод, коробка; ниже серым — топливо, объём, мощность.
  5. Комплектации — горизонтальный скролл карточек: название, сколько опций, цена, бейдж скидки.
  6. Характеристики — сетка 2×2 (двигатель, расход, мощность, кузов) + «Показать все».
  7. Условия кредита — калькулятор: первый взнос, чипы срока, платёж и сумма.
  8. «При покупке авто у нас» — список преимуществ с иконками: трейд-ин, рассрочка, помощь на дорогах.
  9. «Другие авто» — карточки похожих машин внизу.
- **Фичи и UX:** [скрин]
  - при скролле в шапке закрепляются цена и модель;
  - внизу закреплены «Написать в чат» и «Продолжить»;
  - дисклеймер «Пока примерные, точные посчитаем перед покупкой».
- **Что берём себе (предложение для Э3, не решено):**
  - фото, модель, цена за сутки и итог за период крупно;
  - строка «коробка, привод, места, багажник»;
  - сетка ключевых характеристик;
  - «что входит» (страховка, пробег, депозит) — по аналогии с блоком «При покупке авто у нас»;
  - цена в шапке при скролле, «Забронировать» закреплена внизу.

## Вне индустрии (20.10.2026)

Визуал лендинга ищем вне транспорта (не авто, авиа, мото, лодки) — от эмоций концепта.

**Как отбираем** — Илья (С4) + Миша (уроки 2.2, 3.2):
- Ищем на Awwwards, Cosmos по ощущению, не по индустрии. Сначала берём всё, что цепляет, потом выкидываем лишнее.
- Фильтр — вопрос: «это ощущается свободным, антитревожным, без неудобства?» Не «круто ли?»: эффекты ради вау — тревожные.
- Один референс — один слой: типографика, лейаут, цвет, стиль или иллюстрации. Слой забираем целиком, по рецепту — с пропорциями, уровнями, «что на чём».
- Референсы должны сходиться между собой — проверяем при подборе, а не после.
- Внеиндустриальное — только атмосфера. Паттерны формы, подбора и брони не трогаем.

```
- Рецепт: пропорции, уровни, что на чём

```
