# План работ до финала

Обновлён 26.10.2026. Сроки: вт 27.10 — разбор с Мишей, вт 3.11 19:00 — финал.

Фидбек менторов — рекомендации, не задачи. Что из него брать, решает автор; план — его решения.

Порядок по мастер-плану Миши: дизайн-концепция (рефы, рестайлинг) → дизайн-система и полиш → анимации → лендинг → видео на лендинге.

## 1. Рестайлинг по рефам

Новый лейаут, типографика, цвета, стили по визуальным рефам из `intent.md` §5. `references.md` — конкуренты, фон, а не образец. Генерация — через скилл `impeccable`, чтобы не было нейрослопа.

- Структура — пять блоков из `intent.md` §4 (интро с визардом, «Направления», «Машина там, где ты», «Без сюрпризов», FAQ) и флоу подбора, не урезать.
- Playfair уходит вместе со старой типографикой.

## 2. Фото машин

- Решить про гараж: плох ли он для «кино» или наоборот работает как съёмочный павильон.
- Найти несколько ракурсов для одной или 2–3 машин. Машины доступные, не Cybertruck.
- Вариант: взять официальные фото одного бренда (Range Rover — идеальные ракурсы, разные модели под разные задачи).
- Открытый вопрос: что показывать в сетке из ~50 машин.

## 3. Анимации на motion.dev

[Motion](https://motion.dev/) установлен. Входная заставка подключена; после рестайлинга переделать остальные анимации из `animations.md`. Минимум:

- заставка при входе на сайт сервиса — подключена 26.10: 5 с, один раз за сессию, с пропуском;
- заставка подбора;
- смена машины;
- переход к допам;
- переход к брони.

## 4. Сторибук

Как у Миши: токены (цвета, радиусы, шрифты) и компоненты на отдельной странице.
Когда: сразу после рестайлинга (п. 1), до анимаций — на этапе «дизайн-система и полиш». Раньше — переделывать после смены стиля; позже — анимации будут собираться на неустоявшихся компонентах.
