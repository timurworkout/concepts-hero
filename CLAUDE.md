# CLAUDE.md

Концепт для курса: лендинг аренды авто для путешествий по России.
White space: «Машина ждёт тебя, а время поездки остаётся на места».

## Финальный проект

Один концепт: лендинг, который рассказывает и показывает концепт. Лендинг и продукт не разделяются — внутри может быть скролл, кликабельная демка или разбивка по фичам, в зависимости от идеи.

Курс стартовал 28.09.2026. Оставшиеся фидбэки: сб 24.10 (Илья), вт 27.10 (с Мишей), финальный просмотр вт 3.11 в 19:00 МСК (с Мишей) — к нему концепт должен быть готов. Ориентир по неделям:

1. Определиться с идеей концепта.
2. Первый драфт лендинга-презентации.
3. Довести лендинг: анимации, скролл-эффекты, интерактивные демки.
4. Доработать по фидбэкам.

## Где что лежит

- `project/` — контекст проекта для агента. Всё в папке коммитится и пушится: по ней работает облачная сессия.
  - **Опираться в первую очередь** — текущие решения:
    - `intent.md` — стартовый файл и вектор концепта: point of view, название, эмоции, метафоры, исходная идея и рамка курса. Читать первым. Обновляет пользователь, когда корректирует вектор; агент правит его только по прямой просьбе. Если работа расходится с `intent.md` — сказать об этом, а не подгонять файл
    - `feedback.md` — фидбек менторов по сессиям со статусами: что применено, что нет. Рекомендации — не решения, решает пользователь
    - `spec.md` — экраны, состояния, данные
    - `tone-of-voice.md` — тон текстов
    - `animations.md` — анимации и motion-токены
    - `references.md` — найденные рефы с разбором; `ref-sources.md` — где их искать; `img/` — картинки
  - **Фон** — полезно для контекста, но может отставать от решений выше:
    - `research.md` — ресерч рынка и сервисов
    - `interviews/` — интервью с пользователями и их разбор
    - `previews/` — HTML-превью UI-правок до кода
  - `archive/` — устаревшие черновики (путь клиента, моки, идеи для лендинга, черновик POV, прежняя айдентика, разбор дизайн-системы Airbnb). История, а не текущие решения: не опираться без запроса
- `course/` — материалы курса, в репозиторий не входят.
- [Figma](https://www.figma.com/design/gVzet7tgqOTM63wWNlo2TB/Timur-Golotin-Concept) — черновая доска, смотреть только по запросу. Фрейм сдачи `20:2`.

## Как работать

- Задавай пользователю ровно один вопрос за сообщение, с рекомендуемым ответом, и жди. Это правило важнее пачек вопросов из скиллов (например, grilling).
- Отвечай по-русски.
- Карта `project/` выше должна совпадать с папкой. В начале работы сверяй её с `ls project/`: появился новый файл или папка — добавь в нужную группу; файл устарел или противоречит решениям — предложи пользователю перенести его в `archive/`. Правку CLAUDE.md коммить вместе с файлом.
- Типографика на сайте: без висящих предлогов и союзов (в, с, на, для, и…) и без тире в начале строки — неразрывный пробел. Данные из `src/data.js` проходят через `nb()` автоматически; тексты прямо в JSX — писать с `\u00a0` или оборачивать в `nb()`.
