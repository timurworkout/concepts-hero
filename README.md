# Concepts Hero

Концепт для курса по созданию концептов с ИИ: лендинг аренды авто для путешествий по России. Идея и решения — в [project/concept-idea.md](project/concept-idea.md).

- **Лендинг:** https://timurworkout.github.io/concepts-hero/
- **Витрина «Табло»:** https://timurworkout.github.io/concepts-hero/storybook/ — токены, визард с живой механикой, блоки лендинга. Локально: `npm run storybook` (порт 6006).

Оба адреса обновляются автоматически при пуше в `main`.

## Темп работы с агентом (26.10.2026)

Вывод из сессии по варианту «Табло». Концепт нужно **собирать, а не полировать** — ниже то, на чём терялось время.

**Чинить только то, что видно глазом** на скриншотах 1440 и 390. Субпиксельные края, контраст в служебных подписях, 11px в блоке credits — это шум для сдачи концепта, не дефекты. В список «потом».

**Сначала спросить, потом расследовать.** Полчаса ушло на поиск «синей полоски» (оказался край фотографии у границы панели) и на доказательство, что визард на месте (автор открывал превью через `file:///`, где JSX не исполняется). Один вопрос закрыл бы оба случая.

**Не принимать собственный след за баг.** «Предзаполненный город» в поле оказался состоянием после кликов самой автоматизации.

**Проверки — одним пакетом в конце.** Каждый прогон `impeccable detect` — 45 секунд; четыре прогона подряд съели три минуты чистого ожидания. QA после каждой строчки CSS не нужен.

**Про Impeccable:** если детектор требует возни с мелочами — сначала спросить автора, надо ли упарываться. Часть замечаний — ложные срабатывания (фон берётся у родителя, а не у фотографии; хайрлайн-сетка с `gap:1px` читается как «прижатые края»). Подавления с обоснованием — в `.impeccable/config.json`.

**Что экономит время:** переиспользовать настоящие компоненты из `src/` (через `export`), а не копировать механику в превью; адаптировать существующие QA-скрипты вместо новых. Бинарник лежит в `~/.impeccable/bin/<версия>/impeccable` — в PATH его нет.
