## Ориентир по неделям

1. Определиться с идеей концепта.
2. Первый драфт лендинга-презентации.
3. Довести лендинг: анимации, скролл-эффекты, интерактивные демки — вид зафиналенного проекта.
4. Дозадать вопросы по фидбэкам и доделать оставшееся.
